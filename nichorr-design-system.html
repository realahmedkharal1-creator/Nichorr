NICHORR APP · DESIGN SYSTEM v1

Foundations & Components

Reference implementation for every screen in the app. Same brand as nichorr.com, adapted for dense working-tool use: light content canvas (readability for long sessions), dark ink nav, and the citation-marker as a literal functional element throughout — not just marketing decoration.

Color

Ink for navigation and primary text. Paper for the working canvas. Citation blue is the one accent — used for actions, links, and the citation marker. Verified green and conflict rust are reserved strictly for evidence status, never decoration.

Citation marker — the signature element

The same numbered marker from nichorr.com's hero demo, now literally functional: every claim, stat, or figure traceable to a source carries one. Click reveals the source. This is the one place the app is allowed to feel "designed" — everywhere else stays quiet.
